# Outreach Debate Florida

Official website for Outreach Debate's Florida branch. Expanding access to speech and debate for Florida students.

Static HTML/CSS/JS site — no framework, no build step. Hosted on GitHub Pages.

## Pages

- **`index.html`** — Home: hero, marquee ticker, Orange Blossom Scholarship, access on-ramps, mentorship tracks, Instagram feed, footer.
- **`mentor-program.html`** — Mentor/Mentee Program: growth tracks, application steps, Google Form link.

## Design

Mirrors the Outreach Debate Alabama site's design language: deep teal `#297698` background, coral `#EB5354` accents, white body text, Poppins. Buttons are coral pills (radius 15px). Nav is transparent with a white hairline. Animations (scroll-reveal, gradient blobs, marquee, hover lifts) are vanilla JS/CSS — no libraries.

## Instagram feed

The feed on the homepage is rendered from `data/posts.json` (posts as local images in `assets/instagram/`). Refresh it with:

```bash
python3 scripts/refresh-instagram.py
```

The script hits Instagram's public `web_profile_info` endpoint (no login/API key needed) and regenerates `posts.json` + local thumbnails. Instagram rate-limits this endpoint aggressively (~a few requests per hour per IP), so don't run it in a loop; it backs off and exits non-zero on failure, leaving the existing data untouched. After refreshing, commit the new `posts.json` + images.

## Local dev

```bash
python3 -m http.server 8000
# open http://localhost:8000
```

## Deploy

The repo is on GitHub Pages. To update the live site:

```bash
git add -A
git commit -m "..."
git push
```

Pages publishes from the `main` branch automatically. Live at `https://13bravoopsec333.github.io/outreach-debate-fl/`.
